solveSCLP active parameter set
==============================
Only parameters used by solveSCLP and its local helper functions are printed.

0. Fundamental numerical scales
-------------------------------
  Only these absolute numerical tolerance scales are independently tuned. Other numerical tolerances are derived from these by factors.
  feasTol                : 1.0000e-06  -- Generic primal feasibility tolerance used by solveSCLP diagnostics and safeguards.
  tolEXP                 : 5.0000e-05  -- Stopping tolerance for the outer exponential residual max(||h||_inf,||g||_inf).
  numTol                 : 1.0000e-12  -- Fundamental numerical roundoff/floor scale; used to derive tiny denominators and solver floors.

  printLevel                : 1         -- Controls ordinary trace verbosity; larger values print more diagnostic detail.
  debug                     : 1         -- Controls internal debugging behaviour and whether some caught errors are rethrown.
  printParameters           : true      -- If true, prints this grouped active parameter set before the solver trace.
  printHeaderEvery          : 20        -- Number of major iterations between repeated rectangular trace headers.
  storeNDSDiagnostics       : true      -- Stores full no-descent-direction diagnostics on rejected NDS rows.
  printNDSDiagnosticInline  : false     -- Prints full NDS diagnostic blocks immediately instead of only storing them.
  printNDSDiagnosticSummary : true      -- Prints a compact post-run summary of stored NDS diagnostics.
  NDSDiagnosticSummaryTopN  : 8         -- Number of recent NDS rows shown in the post-run NDS summary.
  printKKTBreakdown         : false     -- If true, errorCLP prints detailed KKT component residuals for inner solves.
  errorCLPPrintFactor       : 100       -- Multiplier used by errorCLP when deciding which component residuals to print.

Diagnostic columns, in printed order
------------------------------------
Mj     = Major iteration index. Mj = 0 is the initial point only.
Mi     = Minor line-search index. Mi = 0 means no accepted line-search trial.
mth    = Row method or finalisation code.
           IP   = initial point only.
           CA   = unrestricted cost approximation.
           WQCA = residual-balanced quadratically regularised cost approximation.
           BCQCA = block-selected curvature-regularised cost approximation.
           QCA  = quadratically regularised cost approximation.
           LQCA = local-box quadratically regularised cost approximation.
           GRD  = safeguarded gradient direction.
           LGRD = local-box safeguarded gradient direction.
           PL   = unrestricted final polish accepted.
           PLF  = polish attempted but failed; accepted outer primal returned.
           PLR  = polish solved but was rejected; accepted outer primal returned.
           FX   = fixed-primal dual recovery succeeded at accepted outer iterate.
           FXK  = fixed-primal recovery succeeded but failed final KKT audit.
           FF   = graceful finalisation fallback returning accepted outer primal point.
           MBS = microscopic EB-limited step rejected as no real progress.
why    = Compact row-outcome code.
           Initial-point codes:
             CEN = centredFeasible initial point.
             ELA = elasticFeasible initial point.
             FEA = feasible initial point.
             RLX = relaxedFeasible initial point.
             ONE = algebraic ones initial point.
           Accepted-step limiter codes:
             FS  = full step.
             EX  = explicit linear or box-bound cap.
             DM  = logarithm-domain cap.
             EB  = exponential-boundary cap.
             Q   = coefficient-change cap.
             MV  = numerical-move cap.
             LD  = legacy dx-damping cap converted to lambda.
             BT  = accepted after backtracking below the initial cap.
           Rejection codes:
             TPF = trial-feasibility failure during line search.
             EPF = endpoint-feasibility failure after inner solve.
             DOM = logarithm-domain failure during line search.
             ARM = Armijo sufficient-decrease failure.
             MXR = maximum outer residual acceptance gate failure.
             CRS = curvature-rescue trial failed.
             SOL = inner conic solve failure.
             NDS = no acceptable descent direction.
             NAN = non-finite direction or descent diagnostic.
             EX0 = explicit-bound cap was already zero.
             DM0 = logarithm-domain cap was already zero.
             EB0 = exponential-boundary cap was already zero.
             Q0  = coefficient-change cap was already zero.
             MV0 = numerical-move cap was already zero.
             LM0 = other lambda cap was already zero.
           Terminal/finalisation codes:
             pExh = portfolio exhausted.
             inFl = terminal inner failure.
             tEXP = outer exponential residual tolerance reached.
             tMj  = small accepted merit change near outer tolerance.
             mMj  = maximum major-iteration count reached.
sub    = Step sub-limiter. If why = MV, sub is the active numerical-move cap:
           U1 = relative first-slot affine movement cap.
           U3 = absolute third-slot affine movement cap.
           Z  = movement cap for z = t3 - log(t1).
           EX = explicit-bound fraction cap inside numerical-move damping.
           DX = direct variable-space movement cap.
         Otherwise sub is the ordinary top-level lambda cap: FS, EX, DM, EB, Q, or LD.
lam    = Accepted effective step length in x_next = x_current + lam*dx.
aDm    = lam / raw logarithm-domain lambda limit.
aEx    = lam / raw exponential-boundary lambda limit.
aEp    = lam / raw explicit-bound lambda limit.
aQ     = lam / coefficient-change lambda cap.
aMv    = lam / numerical-move lambda cap.
KKT    = Inner Karush-Kuhn-Tucker residual when available.
Phi    = Selected outer merit at the displayed point.
PhiH   = sum(h). This decomposes Phi only when meritFunction = sumGapLogGap.
PhiG   = sum(g). This decomposes Phi only when meritFunction = sumGapLogGap.
dPhi   = Displayed-point merit change relative to the previous accepted outer point.
pred   = Predicted merit decrease from the local linear model.
rho    = actual decrease / predicted decrease.
curv   = Merit-curvature correction. Accepted rows use E_curv(lam*dx); rejected rows use E_curv(dx).
cRat   = curv divided by the corresponding absolute predicted linear merit change.
errh   = ||h(x)||_inf at the displayed point.
errg   = ||g(x)||_inf at the displayed point.
dEh    = Change in ||h(x)||_inf relative to the previous accepted outer point.
