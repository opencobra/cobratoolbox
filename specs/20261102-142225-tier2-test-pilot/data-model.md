# Data model: Tier-2 test pilot

- **Selected function**: source path, test file, test folder (spec selection table), model
  (`ecoli_core_model`), arities exercised.
- **Reference value**: name, value, model, date 2026-11-02, solver "none"; stated in the test
  header (Tier 5).
- **Defect entry**: III-Defects format in the test header; regenerated into the registry.
- **Style note**: pattern used, runtimes, memory notes, open questions.
